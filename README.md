# House of Queens | Official Landing Page

Welcome to the official repository for **House of Queens**, an exclusive fashion collective and creative hub dedicated to scouting, elevating, and empowering female talent.

## Features

- **Responsive Design:** Dark-themed UI styled with custom CSS.
- **Model Roster Showcase:** Display section for collective profiles and muses.
- **Recruitment Form:** Integrated online application form for prospective models.
- **Automated Email Notifications:** Model applications are forwarded directly to `tallcelestia@gmail.com` using Formspree.

## Project Structure

- `index.html` - Complete web page containing HTML markup and embedded CSS styles.
- `README.md` - Documentation and project overview.

## Deployment

This website is hosted via **GitHub Pages**.

1. Navigated to repository **Settings** -> **Pages**.
2. Set **Source** to `Deploy from a branch` and selected the `main` branch root (`/`).
3. Form submissions require initial email verification via Formspree upon the first submission test.
